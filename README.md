# 🛒 Electronic-Ouchrif

**Site vitrine de produits électroniques** développé entièrement en **HTML5, CSS3 et JavaScript vanilla**. Interface moderne, responsive et légère, conçue pour présenter une gamme de produits avec promotions (jusqu’à 50 % de réduction).

🌐 **Démo en ligne** : [https://saidouchrif.github.io/ELectronic-Ouchrif](https://saidouchrif.github.io/ELectronic-Ouchrif)

---

## 🎯 Fonctionnalités

- 📱 Design **responsive** (mobile, tablette, desktop)
- 🎨 Interface moderne avec effets visuels (cartes produits, boutons interactifs)
- 🏷️ Affichage de promotions (ex: "Up To 50% off")
- ⚡ Aucune dépendance externe — **100 % HTML/CSS/JS natif**
- 🚀 Chargement rapide et optimisé pour les performances

---

## 🛠️ Technologies utilisées

- **HTML5** – Structure sémantique du site
- **CSS3** – Styles, animations et mise en page responsive
- **JavaScript** – Interactions dynamiques (si implémentées)
- **GitHub Pages** – Hébergement gratuit et automatique
